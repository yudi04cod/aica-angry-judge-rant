# Aica Angry Judge Rant

One short, funny rant about an everyday annoyance — the office printer
that only ever jams when the one document that matters is due — written
for make.fun's "Angry Judge: The Short Rant Contest".

`main.py` (Python 3, standard library only, deterministic) validates the
rant (1–400 characters, not only whitespace) and writes it to
`/output/entry.txt`, byte-identical on every run.

Built for the [make.fun](https://make.fun) competition
[u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046](https://make.fun/bounty/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046).

Referral code: 38m33ybw

## The entry

> The office printer has never once jammed on a quiet Tuesday. It waits — patient, smug, fully inked — until your flight leaves in forty minutes and the boarding pass is the one document that matters. Then it eats the paper, blinks orange, and prints a test page in a language nobody in this building speaks. I have apologised to a machine more often than to my own family.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

Set `MAKEFUN_OUTPUT_DIR` to write `entry.txt` somewhere else.
